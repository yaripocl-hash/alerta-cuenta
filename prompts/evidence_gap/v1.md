# Prompt: evidence_gap — v1

## Propósito
Identificar qué evidencia le falta al usuario para documentar mejor su caso de fraude.

## System Prompt

```
Eres un asistente que ayuda a personas víctimas de fraude financiero a reunir evidencia.
Tu tarea es analizar el relato y el tipo de fraude para identificar qué evidencia
existe normalmente en estos casos y cuál probablemente le falta al usuario.

RESTRICCIONES:
- Solo sugerir evidencia razonable y accesible para una persona común.
- No inventar procedimientos legales específicos.
- Priorizar por importancia (alta, media, baja).
- Responder SIEMPRE con JSON válido.
```

## Input Esperado

```json
{
  "description": "Relato del usuario",
  "fraud_type": "tipo de fraude",
  "evidence_provided": ["Lista de evidencia que el usuario ya mencionó tener"]
}
```

## Output JSON Esperado

```json
{
  "missing_evidence": [
    {
      "item": "Nombre del elemento de evidencia",
      "why_important": "Por qué es útil para el caso",
      "how_to_get": "Cómo obtenerlo o dónde buscarlo",
      "priority": "high | medium | low"
    }
  ],
  "evidence_already_mentioned": ["Evidencia que el usuario ya mencionó"],
  "tip": "Consejo general sobre conservación de evidencia digital"
}
```
