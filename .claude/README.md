# .claude — Configuración de Claude Code

Esta carpeta contiene reglas y comandos para Claude Code al trabajar en Alerta Cuenta.

## rules/
Reglas que Claude Code debe seguir en cada sesión:
- `backend.md` — convenciones del backend FastAPI
- `frontend.md` — convenciones del frontend HTML/CSS/JS
- `security.md` — reglas de seguridad no negociables
- `prompts.md` — cómo gestionar prompts versionados
- `competition.md` — contexto y prioridades de la competencia

## commands/
Checklists para tareas frecuentes:
- `review-project.md` — revisión general del proyecto
- `create-backend-feature.md` — pasos para una nueva feature de backend
- `create-frontend-feature.md` — pasos para una nueva feature de frontend
- `review-prompt.md` — checklist antes de activar un nuevo prompt
