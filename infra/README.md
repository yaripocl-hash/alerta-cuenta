# Infra

Configuración de infraestructura del proyecto.

```
infra/
├── supabase/
│   ├── schema.sql    ← Ejecutar en Supabase SQL Editor para crear las tablas
│   ├── seed.sql      ← Datos de prueba para desarrollo
│   └── storage.md    ← Instrucciones para el bucket de evidencia
└── vercel/
    └── deployment.md ← Guía de deploy del frontend en Vercel
```
